# StudyMate — Project Summary for Presentation

## 1. Project Name
StudyMate is an AI-powered study notes application designed to help students store, organize, review, and revise their notes more effectively.

## 2. Main Idea
The project solves a common student problem: notes are often scattered across notebooks, files, and memory. StudyMate brings everything into one smart platform where students can:
- create and manage notes,
- get AI-generated summaries,
- test themselves with quizzes,
- and even interact with the app through Claude Desktop using MCP.

## 3. Problem Statement
Students usually face difficulty in:
- organizing study material,
- revising large amounts of information,
- remembering key concepts,
- and turning notes into useful practice content.

StudyMate addresses this by combining note management with AI assistance.

## 4. Key Features
### Core Features
- Add notes with title, subject, and content
- View all saved notes in one place
- Search notes by title or subject
- Delete notes
- Dark/light theme for better usability

### AI Features
- Generate concise summaries from notes using Anthropic Claude
- Generate multiple-choice quiz questions from the same notes
- Let users test themselves and check their score

### Advanced Feature
- MCP integration with Claude Desktop so notes can be listed or created through AI conversation

## 5. What Makes This Project Special
StudyMate is not just a note-taking app. It combines:
- full-stack web development,
- database management,
- AI integration,
- and AI agent communication through MCP.

This makes it a strong example of a modern full-stack intelligent application.

## 6. Project Architecture
The project is divided into four main parts:

### 1. Landing Page
A simple promotional website built with HTML, CSS, and JavaScript.
It introduces the app and shows its main purpose.

### 2. Client Application
A React + Vite frontend where users can:
- add notes,
- search notes,
- view summaries,
- and take quizzes.

### 3. Backend Server
An Express + Node.js server that:
- handles API requests,
- validates note data,
- connects to MongoDB,
- and communicates with the AI service.

### 4. MCP Server
A separate server that allows Claude Desktop to interact with StudyMate notes directly.
It exposes tools such as:
- list_notes
- create_note

## 7. Tech Stack

### AI
- Anthropic Claude API

### MCP

## 8. Database Design
The app uses MongoDB to store notes.
Each note contains:
- title
- subject
- content
- creation date
- summary (generated by AI)
- quiz data (generated by AI)

## 9. How the App Works
1. The user opens the app and creates a note.
2. The frontend sends the note to the backend.
3. The backend validates the data and stores it in MongoDB.
4. When the user clicks “Summarize,” the backend sends the note content to Anthropic Claude.
5. Claude returns a summary and quiz questions.
6. These are saved with the note and shown to the user.
7. The user can then attempt the quiz and check the result.

## 10. How MCP Integration Works
The MCP server connects StudyMate directly to Claude Desktop.
This allows a user to ask Claude to:
- show existing notes,
- create new notes,
- and manage study content through conversation.

This is a very impressive feature because it shows integration between AI assistants and real applications.

## 11. Folder Structure Overview
- landing/: promotional website
- client/: React frontend

- mcp-server/: Claude-compatible MCP server

## 12. How to Run the Project Locally
### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

### MCP Server (optional)
```bash
cd mcp-server
npm install
npm start
```

## 13. Important Environment Variables
The backend and MCP server need a MongoDB connection string.
The server also needs an Anthropic API key for AI features.

Important variables include:
- MONGODB_URI
- ANTHROPIC_API_KEY
- CLIENT_ORIGIN
